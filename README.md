## 收录标准

清单中的项目通常应满足以下条件：

1. 解决一个清晰、真实的问题，而不是单纯堆叠功能。
2. 官方来源明确；开源与商业软件均可收录，但必须标明授权或收费方式。
3. 项目仍在维护，或已经成熟到不需要频繁更新。
4. 没有已知的强制广告、捆绑安装或误导性下载入口。
5. 用自己的话说明用途和限制，不复制大段官方宣传。

“开源”不自动等于“安全”，“官方网站”也不能替代安装前的基础检查。请核对下载域名、数字签名、发布记录以及软件或硬件要求的权限。
