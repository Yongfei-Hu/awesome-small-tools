## 收录标准

候选软件通常应满足以下条件：

1. 解决一个清晰、真实的问题，而不是单纯堆叠功能。
2. 官方来源明确，优先选择开源项目。
3. 项目仍在维护，或已成熟到不需要频繁更新。
4. 没有已知的强制广告、捆绑安装或误导性下载入口。
5. 推荐理由和缺点都能说清楚。

“开源”不自动等于“安全”。安装前仍应检查下载来源、数字签名、项目发布记录和所需权限。
